# Таврийский Фермер (Tavria Farmer)

🚜 Игра о сельском хозяйстве в Херсонской области (Тавричанская община).

- **Онлайн-игра на GitHub Pages:** [https://loker267.github.io/tavriafermer/](https://loker267.github.io/tavriafermer/)
- **Прямое скачивание архива игры:** [tavria-farmer.zip](https://github.com/Loker267/tavriafermer/raw/main/tavria-farmer.zip)

---

## 🚀 Как работает обновление игры

### 1. Игра онлайн через GitHub Pages
- GitHub Actions автоматически распаковывает `tavria-farmer.zip` при каждом коммите/обновлении репозитория.
- Сайт [https://loker267.github.io/tavriafermer/](https://loker267.github.io/tavriafermer/) обновляется сам в течение 20 секунд.
- При открытии сайта игра сообщает, если вышла новая версия, и обновляет кэш Service Worker по кнопке «Обновить сейчас».

### 2. Игра локально (с диска на ПК / телефоне)
- Игра при запуске считывает `version.json` с этого репозитория.
- При появлении новой версии на экране появляется окно с кнопкой «Скачать vX.X.X (.zip)».
- Скачивается файл `tavria-farmer.zip`, который достаточно распаковать поверх папки игры. Сохранения остаются в `localStorage` и не теряются!

---

## 📦 Как выпускать новые версии
Чтобы выпустить обновление, достаточно загрузить в корень репозитория всего 2 файла:
1. `tavria-farmer.zip` — свежий архив с игрой.
2. `version.json` — файл с новым номером версии и описанием изменений.
